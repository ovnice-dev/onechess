# Code of conduct

Onechess is a place to talk about chess engines with respect and good faith.

- Be kind and patient, especially with newcomers.
- Discuss ideas and measurements, not people.
- No harassment, insults or discrimination of any kind.

Problems can be reported privately to the maintainer through GitHub (see
[SECURITY.md](SECURITY.md) for a private channel). The maintainer may remove
comments, issues or contributions that do not follow these rules.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
